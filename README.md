## 🎯 Features

- **Live Breakout Alerts**: Immediate detection of bullish momentum + heavy Call sellers nearby + >100% PE writing surge.
- **FnO Technicals Scanner**: Spot LTP, VWAP, RSI(14), EMA 9/21, Volume Surge Multipliers across 16+ instruments.
- **Spider-Style Option Chain**: Strike-by-strike Call vs Put Writer visualization with highlighted surge strikes.
- **1-Click Broker Integration**: Instant OAuth login for Fyers API (v3) and Zerodha Kite Connect.
- **Built-in 24/7 Simulator**: Real-time realistic market simulation for testing anytime.
